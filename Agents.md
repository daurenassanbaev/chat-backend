# Цель проекта
Учебный pet-проект для собеседований Java backend (middle).
Ценность: надёжная доставка сообщений (outbox, at-least-once, идемпотентность, ack, DLT, presence), а не продуктовые фичи.

# Правила
- Бизнес-фичи не добавлять (группы, read receipts, unread, typing, вложения, push, поиск).
- Jackson 2 (com.fasterxml), миграцию на Jackson 3 не делать.
- Схема БД только через новые Flyway-миграции, применённые миграции не редактировать.
- Каждое изменение поведения: интеграционный тест (Testcontainers) на сценарий сбоя.
- Сначала план списком, потом код. Один этап — один коммит. Без попутного рефакторинга.
- После этапа: что изменилось, почему, какой компромисс остался, и 3 вопроса автору, как на собеседовании.
